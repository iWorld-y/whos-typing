# Design

## Context

`internal/app/control_view.go` 当前以纵向布局排列终端和底部控制栏。状态文字、错误提示及接管或交还按钮位于同一行；终端的粒子效果由内容区域的 `DrawOver` 绘制。远端接入确认框在控制视图之后绘制。

现有 `agent-terminal-control` 规格要求底部控制栏。本变更只调整该显示要求，控制权状态及其转换仍由现有 Shell 层负责。

## Goals / Non-Goals

**Goals:**

- 让状态、操作按钮及必要的错误提示组成顶部居中的悬浮界面。
- 保留终端焦点、胶囊以外的鼠标交互，以及窗口缩放和减少动态效果时的可用性。

**Non-Goals:**

- 不更改控制权状态机、CLI 协议、60 秒计时或粒子算法。
- 不新增终止任务入口、自动隐藏行为或终端布局设置。

## Decisions

### 使用悬浮布局承载胶囊

将终端区域作为主要内容，控制胶囊作为同一容器中靠后的悬浮元素，锚定内容区域的顶部中央。使用 MyGo 现有的定位能力，让胶囊不参与终端的高度分配；移除原底部整行。胶囊覆盖到终端文字时允许局部遮挡，这是用户确认的取舍。

备选方案是在顶部预留整行空间。该方案可避免遮挡，但会改变终端可用高度，也不符合悬浮效果。

### 将状态和按钮放在同一个胶囊中

Agent 控制与人类手动接管分别复用当前文字和按钮；胶囊使用较通透的毛玻璃背景与清晰的状态文字，降低视觉干扰。交还失败时继续展示原因，必要时在胶囊内换行，避免挤出按钮。普通人类控制状态继续不显示控制胶囊。

正常单行布局下，同时检查状态文字在胶囊内、按钮文字在按钮内的视觉垂直居中。字体字形与布局框可能有不同留白，需要结合实际预览确认，而不是只检查外框尺寸。

备选方案是只移动状态文字，将按钮留在底部。用户已选择将按钮与文字放在一起。

### 使用 MyGo 毛玻璃材质

使用当前 MyGo v0.7.4 自带的 `plugins/glass` 为胶囊模糊其后的终端和粒子，并选择较淡的染色。材质只影响背景，状态文字和按钮保持清晰；不通过整体 `Opacity` 让子元素变淡。交互与控制权逻辑不变。

备选方案是只降低背景颜色的透明度，但它不会模糊下方内容，也容易让文字相互干扰。调整染色时应同时检查深浅终端的可读性及动画运行时的渲染开销。

### 保持绘制和交互边界

粒子仍由终端内容区域绘制；胶囊位于其上方，避免 `DrawOver` 覆盖按钮。远端确认框继续位于控制视图之上。保留现有按钮的焦点处理和标识；胶囊以外的区域不拦截终端鼠标事件。

备选方案是将胶囊作为终端内容区域的子元素，但现有 `DrawOver` 在子元素之后绘制，可能把粒子效果叠到胶囊上。

## Risks / Trade-offs

- [顶部文字被遮挡] → 使用紧凑的胶囊，按已确认方案允许局部遮挡，不引入自动隐藏。
- [窄窗口或错误提示较长时按钮不可见] → 限制胶囊在窗口内布局，并在界面测试中覆盖窄窗口和交还失败。
- [浮层影响输入或对话框层级] → 复用按钮的焦点处理，测试胶囊以外的选择、滚动、键盘焦点与远端确认框。
- [背景模糊与持续粒子绘制增加开销] → 在隔离窗口中观察动画和交互响应，必要时比较 CPU 样本并记录测试限制。

## Migration Plan

本变更不涉及数据迁移。更新界面、相关测试和控制提示位置的说明后发布；如需回退，回退对应的界面与文档改动即可。
