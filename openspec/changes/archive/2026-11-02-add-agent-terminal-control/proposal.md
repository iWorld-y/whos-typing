# Proposal

## Why

当前窗口只在单条 CLI 命令执行期间提示输入被暂停，无法在多次命令之间表达 Agent 是否持有终端控制权。用户需要随时接管终端，并在 Agent 可以控制终端时看到明确的视觉提示。

## What Changes

- 增加 Agent 与人类之间可持续切换的终端控制权。通过 CLI 向终端发起执行或自动输入均视为 Agent 操作，Agent 也可以通过 CLI 主动交还控制权。
- 用户可以立即接管，已开始的命令继续运行；接管期间 Agent 仍可读取终端内容，但不能发送新命令。用户可以在完成操作后将控制权交还 Agent。
- Agent 命令结束后，如果连续 60 秒没有新的执行命令且终端状态可确认，自动交还控制权。自动交还后，Agent 可在终端空闲时重新接管；用户主动接管时，必须等待用户交还。
- Agent 持有控制权时，在终端上显示参考示例中的蓝色光带和粒子效果，并在窗口下方显示「agent 正在控制」和「接管」。人类接管后显示「交还 Agent」。不增加「终止任务」按钮。
- 保留终端只读快照、现有 Shell 会话、本地与远端命令处理，以及人工输入和 Ctrl+C 的既有安全边界。

## Capabilities

### New Capabilities

- `agent-terminal-control`：定义 Agent 与人类的终端控制权、接管和交还、命令完成后的空闲计时，以及与控制权一致的界面提示。

### Modified Capabilities

- `local-terminal`：明确人工键盘输入与终端控制权的关系，同时保留窗口启动后的直接输入和 Ctrl+C 行为。

## Impact

- `internal/shell` 需要区分控制权、命令执行状态和可安全发送命令的状态，覆盖本地 Shell 与已接入的远端 Bash。
- `internal/control` 和 `cmd/whos-typing-cli` 需要提供控制权交还及状态反馈，保留现有 CLI 命令格式和只读快照的使用方式。
- `internal/app` 需要增加底部控制栏与终端特效，并将界面更新接入控制权状态。
- 用户文档和相关测试需要覆盖控制权切换、60 秒计时、远端状态不明和真实终端显示。继续使用上游 MyGo，不引入本地替换。
