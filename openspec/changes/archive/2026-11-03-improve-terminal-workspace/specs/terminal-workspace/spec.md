# Spec Delta

## MODIFIED Requirements

### Requirement: 会话标识稳定且不可复用

系统 SHALL 为每个会话和标签页提供独立于界面位置、名称的 ID。会话和标签 SHALL 分别使用从 `session_01` 和 `tab_01` 开始的十进制序列，数字部分至少两位，超过 99 后自然增长，例如 `session_100`、`tab_100`；两个序列互不影响，分屏不分配标签 ID。移动焦点、改变布局、重命名或关闭其他对象 SHALL 不改变 ID；已关闭对象的 ID SHALL 不被新对象复用，包括应用重启后的对象。无法保证新 ID 唯一且未使用时 SHALL 拒绝创建并报告错误。

#### Scenario: 关闭后创建新会话
- **WHEN** 会话 A 关闭后又创建会话 B
- **THEN** B 获得不同于 A 的完整会话 ID
- **AND** 指向 A 的请求不会作用于 B

#### Scenario: 关闭标签不复用标识
- **WHEN** A、B、C 按顺序排列，关闭 B 后新建 D
- **THEN** 顺序为 A、C、D，D 的 tab_id 不等于 B 的 tab_id
- **AND** A、C 的标签及会话 ID 均不变

#### Scenario: 序号进位与独立分配
- **WHEN** 会话或标签序列从 09 增加到 10，或从 99 增加到 100
- **THEN** 完整 ID 分别使用 `session_09`、`session_10`、`session_100` 或 `tab_09`、`tab_10`、`tab_100`
- **AND** 分屏只递增会话序列，不改变标签序列

#### Scenario: 重启后不复用
- **WHEN** 应用重启并使用保留的应用数据创建新对象
- **THEN** 新标签和会话不使用重启前已经分配的 ID
- **AND** 旧请求不匹配任何新对象

#### Scenario: 无法安全分配标识
- **WHEN** 标识状态损坏、无法保存或标识空间已耗尽
- **THEN** 创建失败并报告原因，不重置分配状态或影响已有会话

### Requirement: 标签页名称独立且可重命名

标签默认名称 SHALL 为 `username@hostname:/path`，使用该标签最后选中窗格最近确认的用户、主机和工作目录，不附加数字编号或内部 ID。元信息变化 SHALL 更新默认名称。CLI SHALL 支持通过稳定 tab_id 重命名并拒绝空白标题；人工名称 SHALL 保留至标签关闭，不受元信息或 Shell OSC 标题覆盖。

#### Scenario: 关闭标签后创建新标签
- **WHEN** 用户关闭一个标签后又创建新标签
- **THEN** 新标签以其会话上下文生成默认名称并追加到末尾，不使用数字名称

#### Scenario: 分屏和创建失败不消耗标签编号
- **WHEN** 已有标签发生分屏，或新标签创建失败
- **THEN** 既有标签 ID 与顺序不变，分屏不会创建额外标签或分配显示编号

#### Scenario: 工作目录与当前窗格更新标题
- **WHEN** 默认命名的标签中当前窗格完成 cd 并报告提示符，或用户选中另一个窗格
- **THEN** 标签名称反映对应窗格最近确认的用户、主机和目录

#### Scenario: 重命名后 Shell 修改标题
- **WHEN** 用户将标签页重命名为 `构建`，随后 Shell 发送新的 OSC 标题或目录元信息
- **THEN** 标签页仍显示 `构建`，列表和当前会话查询返回该 tab_title

#### Scenario: 拒绝空白标题
- **WHEN** CLI 请求将标签页重命名为空或仅含空白字符的标题
- **THEN** 操作失败，原名称和焦点不变

### Requirement: 工作区快捷键独立于终端输入

系统 SHALL 在 macOS 以 `Cmd+T` 新建标签页、`Cmd+D` 向右分屏、`Cmd+Shift+D` 向下分屏，并以 `Cmd+1` 至 `Cmd+9` 切换当前从左到右对应位置的标签。不存在的位置 SHALL 无操作。快捷键 SHALL 在终端输入前处理，在 Agent 控制及搜索框聚焦期间仍可使用，并保留已有命令输入和控制权，不显示新建、分屏或关闭操作按钮栏。

#### Scenario: 快捷键新建标签页
- **WHEN** 用户按下 `Cmd+T`
- **THEN** 在末尾创建使用动态默认标题和新短 ID 的标签并聚焦新会话
- **AND** 原会话不接收该快捷键，已有输入保持不变

#### Scenario: Agent 控制期间向右分屏
- **WHEN** 当前窗格由 Agent 控制，用户按下 `Cmd+D`
- **THEN** 原会话保留在左侧，新会话出现在右侧并获得焦点
- **AND** 原会话仍由 Agent 控制，其命令继续运行

#### Scenario: 向下分屏不触发向右分屏
- **WHEN** 用户按下 `Cmd+Shift+D`
- **THEN** 只创建一个位于当前窗格下方的新会话并聚焦
- **AND** 不额外创建右侧窗格，也不向 Shell 发送输入

#### Scenario: 快捷键仅按位置切换
- **WHEN** 原顺序 A、B、C 中 B 已关闭且 D 新建到末尾，用户按 `Cmd+2`
- **THEN** 切到 C 并恢复 C 最近聚焦窗格，与其 tab_id 和名称无关

#### Scenario: 不存在的快捷键位置
- **WHEN** 只有两个标签而用户按 `Cmd+3` 或 `Cmd+9`
- **THEN** 不切换、不创建标签，按键不发送到 Shell

## ADDED Requirements

### Requirement: 标题与标签共享窗口控制行

macOS 窗口 SHALL 在红绿灯右侧同一行显示标题或标签，保留系统窗口按钮，移除内容区旧标签行及左右滚动按钮。单标签 SHALL 只呈现普通标题而无标签边框或选中样式；多标签 SHALL 等分扣除系统按钮及必要间距后的可用宽度，并清晰显示当前项。标题 SHALL 不显示内部 ID 或位置编号。

#### Scenario: 单标签显示标题
- **WHEN** 窗口只有一个标签，即使其中有多个分屏
- **THEN** 红绿灯右侧只显示该标签标题，标题保留右键关闭菜单入口
- **AND** 内容区没有第二行标签栏

#### Scenario: 两个标签等宽
- **WHEN** 窗口存在两个标题长度不同的标签
- **THEN** 两个标签各占红绿灯右侧可用宽度的一半，不按标题长度分配

#### Scenario: 多标签与窄窗口
- **WHEN** 标签数增加或窗口缩窄
- **THEN** 所有标签继续等宽，过长文字省略，悬停可查看完整标题，不显示左右按钮
- **AND** 各标签仍可点击选中，点击不拖动窗口

#### Scenario: 关闭至一个标签及全屏切换
- **WHEN** 多标签关闭到仅剩一个，或窗口切换全屏状态
- **THEN** 单标签恢复普通标题，布局按实际窗口按钮占位调整，不遮挡系统按钮

### Requirement: 标题元信息更新保持终端行为

本地支持的 Shell 和已完成接入的远端 Bash SHALL 在提示符阶段更新用户、主机与目录元信息，不影响命令退出码、输出、未提交输入或控制权。元信息 SHALL 不进入可见终端文本或命令输出。缺失或非法信息 SHALL 不触发额外终端输入，也不阻塞命令。

#### Scenario: 本地与远端上下文切换
- **WHEN** 用户完成远端 Bash 接入，之后又确认回到本地提示符
- **THEN** 默认标题分别使用已确认的远端和本地上下文，不复用过期远端目录

#### Scenario: 远端状态未知
- **WHEN** 已接入远端失联且尚未确认本地提示符
- **THEN** 保留最后确认的标题上下文并标注状态未知，不猜测本地目录或发送探测命令

#### Scenario: 未接入或异常元信息
- **WHEN** SSH 尚未接入，或收到拆分、非法、过长的元信息
- **THEN** 完整有效信息到达前保留最近确认值，不从任意提示符猜测身份
- **AND** 不泄漏协议标记，不改变正常命令结果；标题中的控制字符以可见转义显示
