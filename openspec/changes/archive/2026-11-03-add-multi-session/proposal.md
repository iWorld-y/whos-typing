# Proposal

## Why

当前窗口只能承载一个 Shell，无法同时查看多个本地或远端工作会话。用户需要通过标签页组织工作，在标签页内嵌套左右、上下分屏，并让 Agent 能创建会话、识别当前聚焦会话和准确发送命令。

## What Changes

- 单窗口支持多个标签页，每页支持递归左右、上下分屏及拖动调整比例，每个窗格拥有独立会话。
- 窗口移除新建、分屏和关闭操作按钮栏，GUI 使用 `Cmd+T` 新建标签页，使用 `Cmd+D` 和 `Cmd+Shift+D` 对当前窗格分屏。关闭当前窗格或标签页的入口位于标签页右键菜单；CLI 也可创建标签页和分屏。GUI 创建后聚焦新会话；CLI 默认保留焦点，可显式请求聚焦。
- 标签页默认按本次应用的创建顺序使用 `01`、`02` 等名称，关闭后不重排或复用编号。CLI 可通过稳定 `tab_id` 重命名，查询结果包含 `tab_title`；名称仅在本次应用运行期间保留，不受 Shell 标题覆盖。
- 增加会话列表、当前聚焦会话查询和显式聚焦操作；会话使用稳定 ID，布局变化不改变 ID。
- 所有会话操作支持 `--session <id>`。**BREAKING**：存在多个会话时，省略目标的旧调用将被拒绝；单会话调用保持兼容。
- Agent 先查询当前聚焦会话，再用返回的 ID 执行连续操作。切换标签页或窗格不会重定向已绑定的请求。
- Shell 退出或关闭窗格只释放对应会话；后台标签页继续接收输出；控制权、远端接入确认和视觉提示按会话隔离。

## Capabilities

### New Capabilities

- `terminal-workspace`: 标签页编号和名称、嵌套分屏、焦点、稳定标识及 GUI 快捷键。
- `session-routing`: CLI 会话发现、目标解析、标签页重命名、协议兼容和请求生命周期隔离。

### Modified Capabilities

- `local-terminal`: 按会话保留 Shell 状态，调整退出与启动失败行为以适应多会话。
- `agent-terminal-control`: 控制权、视觉效果与接入确认作用于指定会话，不受其他会话焦点和活动影响。

## Impact

- `internal/app/` 增加工作区状态与布局管理，拆开会话与窗口生命周期。
- `internal/control/` 增加发现、创建、聚焦和目标路由；`cmd/whos-typing-cli/` 调整参数解析。
- `internal/shell/` 复用现有每会话 PTY、控制权与远端状态，保留输入安全检查。
- 更新 CLI 内置帮助、`skills/whos-typing-cli/SKILL.md`、`docs/development.md` 及相关测试。
- 继续使用上游 MyGo v0.7.4；不引入外部终端复用服务。本次不包含多窗口、重启恢复、广播输入、跨标签页拖拽或复制现有 SSH 连接。
