- [x] 1.1 增加粘贴子命令和能力握手，沿用稳定会话 ID。用 CLI 和控制服务测试验证缺失、未知、已关闭的 ID 及旧 GUI 均不会触发输入，现有执行入口仍可用。

## 2. 终端粘贴与发送回执

- [x] 2.1 接入目标窗格的粘贴编码，核对 MyGo 可用的模式和编码接口。用终端夹具覆盖模式开启、关闭、重置及未知，验证只有可信且实际采用括号粘贴时才具备多行免确认资格。
