# Spec Delta

## MODIFIED Requirements

### Requirement: 标签页承载独立会话

系统 SHALL 在一个窗口内提供标签页的新建、切换和关闭入口，普通新建标签页初始包含一个独立本地 Shell 会话。应用 SHALL 通过显式的受管 SSH 会话入口创建承载远端 Bash 的标签页。GUI SHALL 使用 `Cmd+T` 新建标签页，不显示新建按钮。标签页右键菜单 SHALL 提供关闭标签页和关闭该页最后选中窗格的入口。切换标签页 SHALL 保留其他会话及其输出。

#### Scenario: 切换标签页时命令继续执行
- **WHEN** 标签页 A 的命令持续输出，用户新建并切换到标签页 B
- **THEN** B 显示独立 Shell，A 的命令继续运行并保留输出
- **AND** 切回 A 后能够查看期间产生的输出

#### Scenario: 在同一工作区打开受管 SSH 会话
- **WHEN** 用户显式创建受管 SSH 会话
- **THEN** 工作区创建独立标签页，现有本地和远端窗格的会话与输出保持原状
- **AND** 随后通过普通新建标签或分屏操作创建的窗格仍启动本地 Shell

### Requirement: 标题元信息更新保持终端行为

本地支持的 Shell 和已完成接入的远端 Bash SHALL 在提示符阶段更新用户、主机与目录元信息。受管 SSH 会话 SHALL 通过可信的会话状态更新同样的元信息。更新元信息 SHALL 不影响命令退出码、输出、未提交输入或控制权。元信息 SHALL 不进入可见终端文本或命令输出。缺失或非法信息 SHALL 不触发额外终端输入，也不阻塞命令。

#### Scenario: 本地与远端上下文切换
- **WHEN** 用户完成远端 Bash 接入，之后又确认回到本地提示符
- **THEN** 默认标题分别使用已确认的远端和本地上下文，不复用过期远端目录

#### Scenario: 远端状态未知
- **WHEN** 已接入远端失联且尚未确认本地提示符
- **THEN** 保留最后确认的标题上下文并标注状态未知，不猜测本地目录或发送探测命令

#### Scenario: 未接入或异常元信息
- **WHEN** SSH 尚未接入，或收到拆分、非法、过长的元信息
- **THEN** 完整有效信息到达前保留最近确认值，不从任意提示符猜测身份
- **AND** 不泄漏协议标记，不改变正常命令结果；标题中的控制字符以可见转义显示

#### Scenario: 受管 Bash 切换目录
- **WHEN** 受管 SSH 会话完成工作目录切换，后端报告确认的远端目录
- **THEN** 工作区更新默认标题，已手动命名的标签保留人工名称
- **AND** 系统不向终端发送额外命令以读取标题元信息
