# Tasks

## 1. 远端 Bash 与 SSH 通道

- [x] 1.1 在隔离 SSH 环境实现并验证受管 Bash 的独立命令和状态通道。分别提交 `cd`、`export` 和 `source`，核对后续命令读到实际状态。修改提示符并让程序输出类似通知的文本，核对运行状态和退出码仍正确。
- [x] 1.2 验证远端 PTY 能接收键盘、尺寸变化及 `Ctrl+C`。用等待输入的前台程序和 `sleep` 验证输入到达原前台进程，退出后原 Bash 仍保留目录。覆盖子 Shell 占用前台及受管 Bash 自身退出。
- [x] 1.3 接入 `internal/sshlink` 的连接校验和专属 master。验证两个受管会话复用同一个 master，关闭其中一个只释放对应通道。验证 master 消失及远端启动失败时不回退直连，且回收本次资源。

## 2. 执行后端与 CLI

- [x] 2.1 实现后端的执行准入、输入归属、交还和空闲计时。验证接管与命令提交并发、保留未提交的人工输入、前台忙时明确拒绝、交还后不重放拒绝的请求，以及控制权不会跨窗格改变。
- [x] 2.2 将输出和结果按会话及执行请求关联。测试 CLI 超时或断开后继续消费远端输出、结束前的最后一段输出可读、远端明确返回 255 与 SSH 断线可区分、迟到通知不影响新请求。
- [x] 2.3 扩展本地控制协议和 CLI 创建入口，沿用会话 ID 路由。验证 `ssh open` 返回会话和标签页 ID、旧 GUI 拒绝新入口、无效目标不会回退、`session status --json` 给出实际可用动作，并运行现有协议兼容测试。
- [x] 2.4 在现有 SSH 使用说明中补充受管会话入口、远端运行条件和中断语义。用隔离 SSH 目标按文档执行 `connect`、`open` 和两次独立 CLI 命令，核对示例可用。
