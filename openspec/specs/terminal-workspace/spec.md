# terminal-workspace Specification

## Purpose

为用户和 Agent 提供统一的多会话工作区，通过标签页组织独立终端，并在每个标签页内递归分屏。定义会话标识、焦点和布局操作，使界面选择与后台会话运行保持一致且可被 CLI 查询。

## Requirements

### Requirement: 标签页承载独立会话

系统 SHALL 在一个窗口内提供标签页的新建、切换和关闭入口，每个新标签页初始包含一个独立本地 Shell 会话。GUI SHALL 使用 `Cmd+T` 新建标签页，不显示新建按钮。标签页右键菜单 SHALL 提供关闭标签页和关闭该页最后选中窗格的入口。切换标签页 SHALL 保留其他会话及其输出。

#### Scenario: 切换标签页时命令继续执行
- **WHEN** 标签页 A 的命令持续输出，用户新建并切换到标签页 B
- **THEN** B 显示独立 Shell，A 的命令继续运行并保留输出
- **AND** 切回 A 后能够查看期间产生的输出

### Requirement: 任意窗格支持嵌套分屏

系统 SHALL 允许通过 GUI 或 CLI 将指定窗格左右或上下分屏，新窗格创建独立本地 Shell。GUI SHALL 使用 `Cmd+D` 向右分屏，使用 `Cmd+Shift+D` 向下分屏，不显示分屏按钮。快捷键 SHALL 由应用处理，不发送给终端。已有窗格 SHALL 保留会话 ID 和运行状态；分隔线 SHALL 支持拖动调整比例。

#### Scenario: 生成嵌套四窗格布局
- **WHEN** 用户先左右分屏，再将右侧上下分屏，最后将右下窗格左右分屏
- **THEN** 当前标签页呈现左侧一个、右上一个、右下两个独立会话
- **AND** 拖动任意分隔线只改变对应区域的尺寸，不重建会话

#### Scenario: 对远端窗格分屏
- **WHEN** 已连接远端 Bash 的窗格被分屏
- **THEN** 原连接继续运行，新窗格启动本地 Shell
- **AND** 系统不复制 SSH 连接或重放原会话命令

### Requirement: 会话标识稳定且不可复用

系统 SHALL 为每个会话提供不依赖界面顺序的唯一 ID。移动焦点、改变布局或关闭其他会话 SHALL 不改变该 ID；已关闭会话的 ID SHALL 不被新会话复用，包括应用重启后的会话。

#### Scenario: 关闭后创建新会话
- **WHEN** 会话 A 关闭后又创建会话 B
- **THEN** B 获得不同于 A 的 ID
- **AND** 指向 A 的请求不会作用于 B

### Requirement: GUI 和 CLI 创建采用不同的焦点默认值

GUI 创建标签页或分屏 SHALL 聚焦新会话。CLI 的 `tab new` 和 `session split` SHALL 默认保留选中标签页与聚焦会话，并支持 `--focus` 显式聚焦新会话。成功响应 SHALL 返回新会话 ID 与所属标签页 ID。

#### Scenario: Agent 后台创建标签页
- **WHEN** 用户正在 A 中输入，CLI 创建标签页且未指定 `--focus`
- **THEN** 新标签页创建成功，A 仍然选中且未提交输入保持不变
- **AND** CLI 返回新标签页和新会话的 ID

#### Scenario: 显式聚焦新分屏
- **WHEN** CLI 对 B 分屏并指定 `--focus`
- **THEN** 系统切换到 B 所属标签页并聚焦新窗格
- **AND** 原会话控制权不因焦点变化而切换

### Requirement: 当前会话反映最后选中的终端

系统 SHALL 记录当前标签页的聚焦会话，并在每个标签页内保留最近聚焦窗格。窗口失去系统焦点或用户操作标签栏控件时 SHALL 保留最后选中的终端会话；CLI 显式聚焦 SHALL 切换标签页并选中目标窗格。

#### Scenario: 用户切到 Agent 应用后查询这个会话
- **WHEN** 用户选中会话 A，随后切到其他应用并通过 CLI 查询当前会话
- **THEN** 返回 A 的 ID，并报告窗口不在前台
- **AND** 查询不激活窗口或切换控制权

#### Scenario: 切回已有标签页
- **WHEN** 用户从标签页 B 切回标签页 A
- **THEN** 恢复 A 最近聚焦的存活窗格，当前会话查询随之更新

### Requirement: 关闭窗格收拢布局

关闭窗格 SHALL 只结束对应会话，并让同一分屏中的剩余区域填满原位置。关闭标签页 SHALL 结束其中所有会话；最后一个会话结束时 SHALL 关闭窗口并退出应用。

#### Scenario: 关闭当前窗格
- **WHEN** 用户关闭聚焦窗格，所在标签页还有其他窗格
- **THEN** 剩余区域填补空位，焦点移至存活窗格
- **AND** 其他标签页和会话继续运行

#### Scenario: 关闭标签页
- **WHEN** 用户关闭包含多个会话的标签页且另有标签页存活
- **THEN** 只释放被关闭标签页的全部会话，选中一个存活标签页
- **AND** 当前会话查询不返回已关闭会话

### Requirement: 标签页名称独立且可重命名

每个标签页 SHALL 按本次应用中成功创建的先后顺序获得从 `01` 开始、至少两位的默认名称。关闭标签页 SHALL 不重排或复用编号；重启后可从 `01` 重新开始。CLI SHALL 支持使用稳定 `tab_id` 重命名标签页，拒绝空或纯空白标题。标签名 SHALL 保留至本次应用退出，不受 Shell OSC 标题变化覆盖。

#### Scenario: 关闭标签后创建新标签
- **WHEN** 用户创建 `01`、`02`，关闭 `01`，再创建标签页
- **THEN** 存活标签页名称为 `02` 和 `03`

#### Scenario: 分屏和创建失败不消耗标签编号
- **WHEN** 已有标签页 `01`，用户分屏并经历一次新标签页创建失败，随后成功新建标签页
- **THEN** 新标签页默认名称为 `02`，原标签内的窗格仍属于 `01`

#### Scenario: 重命名后 Shell 修改标题
- **WHEN** 用户将标签页重命名为 `构建`，随后 Shell 发送新的 OSC 标题
- **THEN** 标签页仍显示 `构建`，列表和当前会话查询返回该 `tab_title`

#### Scenario: 拒绝空白标题
- **WHEN** CLI 请求将标签页重命名为空或仅含空白字符的标题
- **THEN** 操作失败，原名称和焦点不变

### Requirement: 工作区快捷键独立于终端输入

系统 SHALL 在 macOS 以 `Cmd+T` 新建标签页、`Cmd+D` 向右分屏、`Cmd+Shift+D` 向下分屏，不显示新建、分屏或关闭操作按钮栏。快捷键 SHALL 在终端输入前处理，在 Agent 控制期间仍可使用，并保留原会话的未提交输入和控制权。

#### Scenario: 快捷键新建标签页
- **WHEN** 用户按下 `Cmd+T`
- **THEN** 创建一个按序编号的新标签页并聚焦其中的新会话
- **AND** 原会话不接收该快捷键，已有输入保持不变

#### Scenario: Agent 控制期间向右分屏
- **WHEN** 当前窗格由 Agent 控制，用户按下 `Cmd+D`
- **THEN** 原会话保留在左侧，新会话出现在右侧并获得焦点
- **AND** 原会话仍由 Agent 控制，其命令继续运行

#### Scenario: 向下分屏不触发向右分屏
- **WHEN** 用户按下 `Cmd+Shift+D`
- **THEN** 只创建一个位于当前窗格下方的新会话并聚焦
- **AND** 不额外创建右侧窗格，也不向 Shell 发送输入
